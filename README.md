El repositorio está organizado de la siguiente manera:

- **src/linkedlist/**  Ejercicios prácticos usando la estructura de datos LinkedList.
- **src/arraylist/**  Ejercicios prácticos usando la estructura de datos ArrayList.
- **src/algoritmos/**  Implementación de algoritmos de ordenamiento y búsqueda.
